## Intent

**Why:** Cockpit defines animations (`shimmer`, `breathe`, `traceable-connector`) directly in `globals.css`. Moving these to pcampus-ui means every service gets consistent animation — no per-service animation drift. Motion must feel cohesive across the Pcampus platform.

**Done when:**
- All standard keyframes come from `@pcampus-studio/ui/dist/motion.css`
- Services never write `@keyframes` from scratch — they import from the library
- `useMotionPreference()` hook available for components that need to respect accessibility

## `useMotionPreference` hook

```ts
// src/motion/hooks/use-motion-preference.ts
export function useMotionPreference(): 'full' | 'reduced' {
  const [preference, setPreference] = useState<'full' | 'reduced'>('full');
  useEffect(() => {
    const mq = window.matchMedia('(prefers-reduced-motion: reduce)');
    setPreference(mq.matches ? 'reduced' : 'full');
    const handler = (e: MediaQueryListEvent) =>
      setPreference(e.matches ? 'reduced' : 'full');
    mq.addEventListener('change', handler);
    return () => mq.removeEventListener('change', handler);
  }, []);
  return preference;
}
```
