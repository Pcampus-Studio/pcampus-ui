## Context

Implements ADR-0002. Adds the missing "data/app-screen" tier to `@pcampus-studio/ui` so embedded apps (Mail, Storage) compose polished screens instead of re-inventing tables/icons per app. Reference look: `mail-ux-redesign-mockup.html`.

## Intent

**Why:** Embedded app screens are weak because the library lacks tables, a standard icon set, and page patterns — so each screen is hand-rolled inconsistently.

**Done when:** `DataTable`, `Icon` (lucide), `PageHeader`, `KpiCard`, `StatusBadge`, `Stepper`, `Timeline`, `FilterBar` are exported from `@pcampus-studio/ui`, token-driven, theme-aware, documented, and consumable by Mail/Storage.

**Unblocks:** Mail screen redesign, Storage UI, console consistency.

## Work steps

1. `DataTable<T>` + `Table` primitives — columns config, header, row hover, `onRowClick?`, actions cell; `loading` → skeleton rows, `empty` → `EmptyState`, `error` → `Alert`.
2. Add `lucide-react`; export curated `Icon` (or re-export) with size/color conventions; document the allowed set used by Mail (send, copy, plus, search, globe, calendar, users, activity, settings, edit, check, alert, export, save, beaker, sparkles).
3. Build page patterns from existing primitives + tokens: `PageHeader`, `KpiCard`, `StatusBadge`, `Stepper`, `Timeline`, `FilterBar`.
4. Export all from `index.ts`; verify light/dark tokens; add Storybook stories showing every state.
