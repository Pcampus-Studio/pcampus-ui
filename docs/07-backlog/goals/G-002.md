## Context

Implements the full `--pcampus-*` token set defined in `docs/03-architecture/design-tokens.md`. All components in G-003–G-006 depend on these tokens existing. No hardcoded values in any component.

## Intent

**Why:** Without tokens, every subsequent component must hardcode colors and spacing — then every brand override breaks. Tokens are the shared foundation.

**Done when:** `import { tokens } from '@pcampus/ui'` works. `--pcampus-color-primary` resolves on `:root` when the CSS is imported. All 7 token categories are covered (color, typography, spacing, border, shadow, motion, layout).

**Unblocks:** All component goals (G-003–G-006)

## Work steps

1. Copy the **Complete Reference Sheet** from `docs/03-architecture/design-tokens.md` into `code/src/tokens/index.css` — verbatim, including dark mode `@media` block
2. Create `code/src/tokens/index.ts` — export a typed `tokens` object mirroring every CSS variable name as a camelCase JS key with the raw value string
3. Export from barrel: `export * as tokens from './tokens'` in `src/index.ts`
4. Create `code/stories/tokens.stories.tsx` — display colour swatches for all semantic color tokens
5. Create `code/tests/tokens.test.ts` — assert that key exports exist (`tokens.pcampusColorPrimary` etc.)
