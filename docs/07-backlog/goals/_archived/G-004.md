## Context

Form controls used across all Pcampus services — PIP (login, profile), Cockpit (entity forms), Factory (product management), BuatJai (booking). These must be accessible and keyboard-navigable.

## Intent

**Why:** Every service has forms. Without shared form controls, each service builds its own — with different error states, different label patterns, different spacing.

**Done when:** All form controls have correct ARIA roles, keyboard navigation, error states, and token-only styling. Stories show all states. Tests cover keyboard interaction.

## Component specs

### Input

```typescript
interface InputProps extends React.InputHTMLAttributes<HTMLInputElement> {
  label?: string;
  hint?: string;
  error?: string;
  leftElement?: React.ReactNode;   // icon or prefix
  rightElement?: React.ReactNode;  // icon, button, or suffix
  size?: 'sm' | 'md' | 'lg';
}
```

States: default, focus, filled, error, disabled

### Textarea

```typescript
interface TextareaProps extends React.TextareaHTMLAttributes<HTMLTextAreaElement> {
  label?: string;
  hint?: string;
  error?: string;
  resize?: 'none' | 'vertical' | 'auto';
  rows?: number;
}
```

### Select

```typescript
interface SelectProps extends React.SelectHTMLAttributes<HTMLSelectElement> {
  label?: string;
  hint?: string;
  error?: string;
  placeholder?: string;
  options: Array<{ value: string; label: string; disabled?: boolean }>;
  size?: 'sm' | 'md' | 'lg';
}
```

### Checkbox

```typescript
interface CheckboxProps extends Omit<React.InputHTMLAttributes<HTMLInputElement>, 'type'> {
  label?: string;
  hint?: string;
  error?: string;
  indeterminate?: boolean;
}
```

### Radio

```typescript
interface RadioProps extends Omit<React.InputHTMLAttributes<HTMLInputElement>, 'type'> {
  label?: string;
  hint?: string;
}

interface RadioGroupProps {
  name: string;
  value?: string;
  onChange?: (value: string) => void;
  options: Array<{ value: string; label: string; disabled?: boolean }>;
  orientation?: 'vertical' | 'horizontal';
}
```

### Toggle (Switch)

```typescript
interface ToggleProps {
  checked?: boolean;
  onChange?: (checked: boolean) => void;
  label?: string;
  size?: 'sm' | 'md';
  disabled?: boolean;
}
```

### FormField (wrapper — optional standalone use)

```typescript
interface FormFieldProps {
  label?: string;
  hint?: string;
  error?: string;
  required?: boolean;
  children: React.ReactNode;
}
```
