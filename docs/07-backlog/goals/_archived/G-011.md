## Intent

**Why:** Cockpit has 4 local chart components that use hardcoded Cockpit colors. Moving them to pcampus-ui ensures all services get consistent chart styling sourced from `--pcampus-color-*` tokens. Any new service needing a funnel or KPI chart doesn't have to build from scratch.

**Done when:** All 6 chart components available from `@pcampus-studio/ui`; colors driven by tokens; Cockpit can consume without visual regression.

## Architecture

All charts use **Recharts** as the rendering engine. pcampus-ui provides:
1. Token-mapped color constants from `--pcampus-color-*`
2. Responsive wrappers with consistent sizing
3. Generic prop interfaces (no domain data types)
4. Pre-styled tooltips, legends, axes using `--pcampus-*` tokens

### Color system for charts

```ts
// src/charts/colors.ts — derived from CSS vars at render time
export const chartColors = {
  primary:   'var(--pcampus-color-primary)',
  success:   'var(--pcampus-color-success)',
  warning:   'var(--pcampus-color-warning)',
  error:     'var(--pcampus-color-error)',
  neutral:   'var(--pcampus-color-text-tertiary)',
  // Palette for multi-series charts
  palette: [
    'var(--pcampus-color-primary)',
    'var(--pcampus-color-success)',
    'var(--pcampus-color-warning)',
    'var(--pcampus-chart-teal)',    // new token
    'var(--pcampus-chart-purple)',  // new token
  ],
} as const;
```

Add chart-specific tokens to `src/tokens/index.css`:
```css
--pcampus-chart-teal:   #1A7A6E;
--pcampus-chart-purple: #5A3F99;
--pcampus-chart-amber:  #C87533;
```

### Component interfaces

```tsx
// FunnelChart
interface FunnelChartProps {
  data: Array<{ label: string; value: number; color?: string }>;
  height?: number;
  showValues?: boolean;
  showPercentages?: boolean;
}

// FunnelMiniChart — compact sparkline-style funnel
interface FunnelMiniChartProps {
  data: Array<{ value: number }>;
  width?: number;
  height?: number;
  color?: string;  // defaults to --pcampus-color-primary
}

// KpiChart — metric display with trend sparkline
interface KpiChartProps {
  label: string;
  value: string | number;
  trend?: Array<{ value: number }>;
  trendColor?: 'positive' | 'negative' | 'neutral';
  delta?: string;  // e.g. "+12.5%"
}

// LineChart
interface LineChartProps {
  data: Array<Record<string, number | string>>;
  lines: Array<{ key: string; label: string; color?: string }>;
  xKey: string;
  height?: number;
  showGrid?: boolean;
  showLegend?: boolean;
}

// BarChart
interface BarChartProps {
  data: Array<Record<string, number | string>>;
  bars: Array<{ key: string; label: string; color?: string }>;
  xKey: string;
  height?: number;
  layout?: 'vertical' | 'horizontal';
  showGrid?: boolean;
  showLegend?: boolean;
}

// SankeyChart
interface SankeyChartProps {
  nodes: Array<{ id: string; name: string }>;
  links: Array<{ source: string; target: string; value: number }>;
  height?: number;
  nodeColor?: string;
  linkColor?: string;
}
```
