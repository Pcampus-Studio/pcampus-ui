## Context

Other developers and services (PIP, BuatJai, Factory, etc.) need to `npm install @pcampus-studio/ui` without cloning this repo. GitHub Packages provides a private registry under the existing Pcampus-Studio GitHub org — no additional cost, no extra service.

## Intent

**Why:** Without a registry, every consuming service must `file:` reference and clone this repo. With GitHub Packages, any dev with a GitHub token does `npm install` like any other package.

**Done when:** `npm install @pcampus-studio/ui` works from any service repo after one-time `.npmrc` setup. A push to `main` triggers automatic publish via GitHub Actions.

## Package name

Use `@pcampus-studio/ui` — matches the GitHub org `Pcampus-Studio`. The name `@pcampus` scope on public npm may not be available.

Internal usage stays the same — just the install name changes:
```bash
npm install @pcampus-studio/ui
```
```tsx
import { Button } from '@pcampus-studio/ui';
```

## Work steps

### 1. Update `code/package.json`

```json
{
  "name": "@pcampus-studio/ui",
  "version": "0.0.1",
  "publishConfig": {
    "registry": "https://npm.pkg.github.com",
    "access": "restricted"
  }
}
```

### 2. Add `.npmrc` at repo root

```
@pcampus-studio:registry=https://npm.pkg.github.com
```

> Do NOT put auth token in `.npmrc` — it goes in `~/.npmrc` on each dev machine or in GitHub Actions secrets.

### 3. Create GitHub Actions workflow

Create `.github/workflows/publish.yml`:

```yaml
name: Publish to GitHub Packages

on:
  push:
    branches: [main]
    paths:
      - 'code/**'

jobs:
  publish:
    runs-on: ubuntu-latest
    permissions:
      contents: read
      packages: write
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: '20'
          registry-url: 'https://npm.pkg.github.com'
          scope: '@pcampus-studio'
      - name: Install dependencies
        run: cd code && npm ci
      - name: Build
        run: cd code && npm run build
      - name: Run tests
        run: cd code && npm run test
      - name: Publish
        run: cd code && npm publish
        env:
          NODE_AUTH_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

### 4. Create `DEV-SETUP.md`

```markdown
# Developer setup — @pcampus-studio/ui

## One-time machine setup

1. Create a GitHub Personal Access Token:
   - Go to GitHub → Settings → Developer settings → Personal access tokens (classic)
   - Scope: `read:packages`

2. Add to your `~/.npmrc`:
   ```
   @pcampus-studio:registry=https://npm.pkg.github.com
   //npm.pkg.github.com/:_authToken=YOUR_TOKEN_HERE
   ```

## Install in a service

```bash
npm install @pcampus-studio/ui
```

## Import

```
```
