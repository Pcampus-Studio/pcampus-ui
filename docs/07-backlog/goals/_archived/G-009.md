## Intent

**Why:** After G-008, services WITHOUT Tailwind can use `dist/index.css` (pre-built). But services WITH their own Tailwind (like Cockpit) need a different entry — one that extends their Tailwind setup rather than shipping pre-built classes. Without `theme.css`, each service must manually map `--pcampus-*` tokens to Tailwind utilities, which leads to drift.

**Done when:** A consuming service can write:
```css
@import "tailwindcss";
@import "@pcampus-studio/ui/dist/theme.css";
```
…and immediately use `bg-primary`, `text-ink`, `bg-canvas`, `border-hairline`, `font-sans`, `rounded-md`, `duration-panel` as Tailwind utilities — identical names to what Cockpit currently uses.

**Unblocks:** Cockpit G-024 (remove local token system, import from library)

## Architecture

`theme.css` does NOT contain `@import "tailwindcss"` — services provide that themselves.  
It ONLY contains:
1. `@import "../tokens/index.css"` — loads all `--pcampus-*` vars
2. `@theme inline { ... }` — maps `--pcampus-*` → standard Tailwind utility names

**Two entry points after this goal:**

| File | For | Usage |
|------|-----|-------|
| `dist/index.css` | Services WITHOUT Tailwind | `import '@pcampus-studio/ui/dist/index.css'` |
| `dist/theme.css` | Services WITH Tailwind | After `@import "tailwindcss"`, add `@import "@pcampus-studio/ui/dist/theme.css"` |

## Work steps

### Step 1 — Create `src/styles/theme.css`

```css
/**
 * @pcampus-studio/ui — Tailwind theme preset
 *
 * Usage (services that use Tailwind v4):
 *   @import "tailwindcss";
 *   @import "@pcampus-studio/ui/dist/theme.css";
 *
 * Do NOT use alongside dist/index.css — they overlap.
 * Use dist/index.css for services without Tailwind.
 */

@import "../tokens/index.css";

@theme inline {
  /* ─── Colors ──────────────────────────────── */
  --color-primary:         var(--pcampus-color-primary);
  --color-primary-hover:   var(--pcampus-color-primary-hover);
  --color-on-primary:      var(--pcampus-color-text-inverse);
  --color-ink:             var(--pcampus-color-text);
  --color-body:            var(--pcampus-color-text-secondary);
  --color-muted:           var(--pcampus-color-text-tertiary);
  --color-canvas:          var(--pcampus-color-surface);
  --color-canvas-soft:     var(--pcampus-color-surface-subtle);
  --color-surface-card:    var(--pcampus-color-surface-card);
  --color-hairline:        var(--pcampus-color-border);
  --color-hairline-strong: var(--pcampus-color-border-strong);
  --color-success:         var(--pcampus-color-success);
  --color-error:           var(--pcampus-color-error);
  --color-warning:         var(--pcampus-color-warning);
  /* ─── Typography ──────────────────────────── */
  --font-sans:             var(--pcampus-font-sans);
  --font-mono:             var(--pcampus-font-mono);
  /* ─── Border radius ───────────────────────── */
  --radius-xs:             var(--pcampus-radius-xs);
  --radius-sm:             var(--pcampus-radius-sm);
  --radius-md:             var(--pcampus-radius-md);
  --radius-lg:             var(--pcampus-radius-lg);
  --radius-xl:             var(--pcampus-radius-xl);
  --radius-full:           9999px;
  /* ─── Motion ──────────────────────────────── */
  --duration-micro:        var(--pcampus-duration-micro);
  --duration-fast:         var(--pcampus-duration-fast);
  --duration-panel:        var(--pcampus-duration-panel);
  --duration-story:        var(--pcampus-duration-story);
  --ease-standard:         var(--pcampus-ease-standard);
  --ease-enter:            var(--pcampus-ease-enter);
  --ease-exit:             var(--pcampus-ease-exit);
  /* ─── Shadows ─────────────────────────────── */
  --shadow-sm:             var(--pcampus-shadow-sm);
  --shadow-md:             var(--pcampus-shadow-md);
  --shadow-lg:             var(--pcampus-shadow-lg);
}
```
