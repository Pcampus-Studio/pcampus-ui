## Intent

**Why:** `src/styles/theme.css` `@theme inline` maps only **unprefixed** utility
names (`--color-ink`, `--color-canvas-soft`, `--color-surface-card`). But every
pcampus-ui component uses **prefixed** classes — `text-pcampus-ink`,
`bg-pcampus-canvas-soft`, `ring-pcampus-primary` (confirmed in `app-shell.tsx`,
`card.tsx`, `form-field.tsx`, `tooltip.tsx`, `popover.tsx`, `kpi-chart.tsx`, …).

`@source` scanning finds those class names, but Tailwind can only emit CSS for
them if a matching `--color-pcampus-*` theme variable exists. It does not — so
`bg-pcampus-canvas` etc. resolve to nothing and **every library component renders
unstyled in every consuming repo**. G-014 shipped the unprefixed mapping; this
goal adds the prefixed one the components actually need.

**Done when:**
- `@theme inline` defines `--color-pcampus-*` for all 14 roles the components use.
- A consuming service (e.g. fleet-monitor dashboard, Cockpit) renders fully
  styled with only `@source` + `@import "dist/theme.css"` — no local `@theme` bridge.
- A test fails if a component introduces a `-pcampus-*` class with no mapping.

## Architecture

Add to the existing `@theme inline` block in `src/styles/theme.css` (keep the
unprefixed entries for backward compat — additive, non-breaking):

```css
@theme inline {
  /* existing unprefixed mappings stay … */

  /* prefixed — what the library's own components consume */
  --color-pcampus-primary:         var(--pcampus-color-primary);
  --color-pcampus-primary-hover:   var(--pcampus-color-primary-hover);
  --color-pcampus-on-primary:      var(--pcampus-color-text-inverse);
  --color-pcampus-ink:             var(--pcampus-color-text);
  --color-pcampus-body:            var(--pcampus-color-text-secondary);
  --color-pcampus-muted:           var(--pcampus-color-text-tertiary);
  --color-pcampus-canvas:          var(--pcampus-color-surface);
  --color-pcampus-canvas-soft:     var(--pcampus-color-surface-subtle);
  --color-pcampus-surface-card:    var(--pcampus-color-surface-card);
  --color-pcampus-hairline:        var(--pcampus-color-border);
  --color-pcampus-hairline-strong: var(--pcampus-color-border-strong);
  --color-pcampus-success:         var(--pcampus-color-success);
  --color-pcampus-error:           var(--pcampus-color-error);
  --color-pcampus-warning:         var(--pcampus-color-warning);
}
```

Roles derived from scanning `src/`:
`primary, primary-hover, on-primary, ink, body, muted, canvas, canvas-soft,
surface-card, hairline, hairline-strong, success, error, warning`.
