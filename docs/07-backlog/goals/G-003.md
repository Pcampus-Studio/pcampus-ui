## Context

The smallest useful set of primitives — everything else builds on these. Button establishes the component API pattern (forwarded ref, variant prop, token-only styling) that all subsequent components must follow.

## Intent

**Why:** Button is the atomic unit of interaction. Badge, Spinner, Skeleton appear inside almost every other component. Getting these right first sets the pattern for the whole library.

**Done when:** All 5 components pass the 6-stage publish gate in `review.md`. Stories cover all variants. Tests cover render and interaction.

**Unblocks:** G-005 (overlays use Button), G-006 (layout uses Spinner, Skeleton)

## Component specs

### Button

```typescript
interface ButtonProps extends React.ButtonHTMLAttributes<HTMLButtonElement> {
  variant?: 'primary' | 'secondary' | 'ghost' | 'destructive';
  size?: 'sm' | 'md' | 'lg';
  loading?: boolean;
  leftIcon?: React.ReactNode;
  rightIcon?: React.ReactNode;
}
```

Variants use token-only styling:
- `primary` — `--pcampus-color-primary` background, white text
- `secondary` — white background, `--pcampus-color-primary` border + text
- `ghost` — transparent, `--pcampus-color-text-secondary` text, hover bg
- `destructive` — `--pcampus-color-error` background, white text
- `loading` — disabled + spinner replaces content

### Badge

```typescript
interface BadgeProps {
  variant?: 'default' | 'primary' | 'success' | 'warning' | 'error' | 'neutral';
  size?: 'sm' | 'md';
  dot?: boolean;        // show dot instead of text
  children?: React.ReactNode;
}
```

### Avatar

```typescript
interface AvatarProps {
  src?: string;
  name?: string;        // fallback initials from name
  size?: 'xs' | 'sm' | 'md' | 'lg';
  shape?: 'circle' | 'square';
}
```

### Spinner

```typescript
interface SpinnerProps {
  size?: 'sm' | 'md' | 'lg';
  color?: 'primary' | 'white' | 'neutral';
}
```

### Skeleton

```typescript
interface SkeletonProps {
  width?: string | number;
  height?: string | number;
  radius?: 'sm' | 'md' | 'full';
  lines?: number;       // render N stacked skeleton lines
}
```
