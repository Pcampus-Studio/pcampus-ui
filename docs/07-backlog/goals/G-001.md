## Context

Bootstrap `code/` so every subsequent goal has a working build, test, and Storybook environment. Nothing ships until this passes.

## Intent

**Why:** All other goals depend on being able to build, test, and document components. Without this scaffold, nothing else can be implemented or verified.

**Done when:** `cd code && npm run build` produces `dist/esm/` and `dist/cjs/`. `npm run test` reports 0 failures. `npm run storybook` starts without errors. `npm run lint` passes.

**Unblocks:** G-002 (tokens), G-003 (primitives), G-004 (forms), G-005 (overlays), G-006 (layout)

## Work steps

1. Create `code/package.json` — name `@pcampus/ui`, version `0.0.1`, type `module`
2. Create `code/tsconfig.json` — strict mode, `jsx: react-jsx`, target `ES2020`
3. Install and configure tsup — dual ESM + CJS output, declarations included
4. Install and configure ESLint — TypeScript + React rules
5. Install Storybook 8 — React + Vite builder
6. Install Vitest + `@testing-library/react` + `@testing-library/jest-dom`
7. Create `code/src/index.ts` — empty barrel, export placeholder
8. Create `code/src/tokens/`, `code/src/primitives/`, `code/src/layout/`, `code/src/charts/` — empty dirs with `.gitkeep`
9. Create `code/stories/` and `code/tests/` — empty dirs
10. Run all four commands and confirm no errors
