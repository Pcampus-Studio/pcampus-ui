## Context

Structural patterns that give every Pcampus service the same shell and data display patterns. `AppShell` is the prerequisite for a unified Pcampus Console. `SnapshotPanel` is the canonical entity detail view pattern across all services.

## Intent

**Why:** The "feels like one product" goal is impossible without a shared shell. Services that use `AppShell` from `@pcampus/ui` can be composed into a console. Services that build their own shell cannot.

**Done when:** A service can import `AppShell`, pass its nav items as props, and have a complete top nav + collapsible sidebar + scrollable content area with Pcampus visual styling. `SnapshotPanel` renders label-value rows correctly.

**Unblocks:** Future Pcampus Console goal (not in this repo)

## Component specs

### ThemeProvider

```typescript
interface ThemeProviderProps {
  theme?: 'light' | 'dark' | 'system';   // default 'system'
  tokenOverrides?: Record<string, string>; // override semantic tokens
  children: React.ReactNode;
}
```

Injects token CSS file, applies theme class to root, supports service-level token overrides.

### AppShell

```typescript
interface NavItem {
  label: string;
  icon?: React.ReactNode;
  href?: string;
  onClick?: () => void;
  active?: boolean;
  badge?: string | number;
  children?: NavItem[];      // nested nav (collapsible section)
}

interface AppShellProps {
  serviceName: string;
  logo?: React.ReactNode;
  navItems: NavItem[];
  topBarRight?: React.ReactNode;  // user avatar, notifications, etc.
  sidebarCollapsed?: boolean;
  onSidebarToggle?: (collapsed: boolean) => void;
  children: React.ReactNode;
}
```

Layout:
- Top bar: 48px height (`--pcampus-layout-nav-height`), service name/logo left, `topBarRight` right
- Sidebar: 240px expanded / 64px collapsed (`--pcampus-layout-sidebar-width/collapsed`)
- Content: `flex-1`, `overflow-y: auto`, `padding: --pcampus-space-8`
- Sidebar toggle: collapse to icon-only on click or at breakpoint `< 768px`

### SnapshotPanel

```typescript
interface SnapshotRow {
  label: string;
  value: React.ReactNode;
  copyable?: boolean;      // shows copy button on hover
}

interface SnapshotSection {
  title?: string;
  subtitle?: string;
  rows: SnapshotRow[];
}

interface SnapshotPanelProps {
  sections: SnapshotSection[];
  loading?: boolean;       // shows skeleton rows
  className?: string;
}
```

Visual spec:
- Label left-aligned, value right-aligned, both `--pcampus-text-sm`
- No card borders, no background boxes — flush layout
- Section divider: 1px `--pcampus-color-border` between sections
- Section title: `--pcampus-text-xs` uppercase, `--pcampus-color-text-tertiary`

### SplitPanel

```typescript
interface SplitPanelProps {
  left: React.ReactNode;
  right?: React.ReactNode;
  leftWidth?: string;        // CSS width, default '360px'
  rightCollapsed?: boolean;
  onRightToggle?: (collapsed: boolean) => void;
  children?: React.ReactNode; // if provided, replaces left+right with single-slot
}
```

Used for master-detail layouts (list left, detail right).

### Alert

```typescript
interface AlertProps {
  variant?: 'info' | 'success' | 'warning' | 'error';
  title?: string;
  description?: string;
  action?: { label: string; onClick: () => void };
  dismissible?: boolean;
  onDismiss?: () => void;
  children?: React.ReactNode;
}
```

### EmptyState

```typescript
interface EmptyStateProps {
  icon?: React.ReactNode;
  title: string;
  description?: string;
  action?: { label: string; onClick: () => void };
}
```

## Notes for AI

- Read: [.agents/design.md](../../../.agents/design.md) — AppShell pattern, SnapshotPanel pattern
- Read: [docs/03-architecture/design-tokens.md](../../03-architecture/design-tokens.md) — layout token values
- AppShell sidebar: use CSS Grid for the shell layout, not absolute positioning
- Sidebar collapsed state: show icon only (hide text), `title` attribute on nav items for native tooltip
- SnapshotPanel: do NOT use card borders — flush rows with divider between sections only
- ThemeProvider `tokenOverrides`: inject a `<style>` tag with `:root { --pcampus-color-primary: ... }` override
- `SplitPanel` right panel collapse: animate width to 0 using `--pcampus-duration-panel`
