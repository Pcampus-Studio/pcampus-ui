## Context

Overlays appear in every service — confirmation dialogs (Cockpit entity deletion), success toasts (BuatJai booking confirmation), contextual menus (Factory product actions), help tooltips (PIP onboarding). These must be accessible (focus trap, ARIA, keyboard escape).

## Intent

**Why:** Without shared overlays, each service implements its own modal with different focus trap behaviour, different animation, different backdrop — breaking the "one product" feel.

**Done when:** Modal traps focus and returns it on close. Toast queues and auto-dismisses. All overlays keyboard-escapable. All use `--pcampus-shadow-modal`, `--pcampus-duration-panel`, `--pcampus-ease-enter/exit`.

## Component specs

### Modal

```typescript
interface ModalProps {
  open: boolean;
  onClose: () => void;
  title?: string;
  description?: string;
  size?: 'sm' | 'md' | 'lg' | 'xl' | 'full';
  closeOnBackdrop?: boolean;   // default true
  children: React.ReactNode;
  footer?: React.ReactNode;    // action buttons
}
```

Animation: fade in backdrop + slide up panel (`--pcampus-duration-panel`, `--pcampus-ease-enter`)  
Focus trap: first focusable element on open, return to trigger on close  
Keyboard: Escape closes

### Dialog (confirm variant)

```typescript
interface DialogProps {
  open: boolean;
  onClose: () => void;
  title: string;
  description?: string;
  variant?: 'default' | 'destructive';
  confirmLabel?: string;
  cancelLabel?: string;
  onConfirm: () => void;
  loading?: boolean;           // shows spinner on confirm button
}
```

### Toast

```typescript
interface ToastProps {
  variant?: 'default' | 'success' | 'error' | 'warning';
  title: string;
  description?: string;
  duration?: number;           // ms, default 4000, 0 = persist
  action?: { label: string; onClick: () => void };
  onClose?: () => void;
}

// Provider + hook
function ToastProvider({ children }: { children: React.ReactNode }): JSX.Element
function useToast(): { toast: (props: ToastProps) => void; dismiss: (id: string) => void }
```

Position: bottom-right (desktop), bottom-center (mobile)  
Queue: max 3 visible, FIFO

### Tooltip

```typescript
interface TooltipProps {
  content: string;
  placement?: 'top' | 'bottom' | 'left' | 'right';
  delay?: number;              // ms, default 400
  disabled?: boolean;
  children: React.ReactElement;
}
```

### Popover

```typescript
interface PopoverProps {
  open?: boolean;              // controlled
  defaultOpen?: boolean;       // uncontrolled
  onOpenChange?: (open: boolean) => void;
  trigger: React.ReactElement;
  content: React.ReactNode;
  placement?: 'top' | 'bottom' | 'left' | 'right';
  closeOnClickOutside?: boolean;
}
```

### Dropdown (menu)

```typescript
interface DropdownItem {
  label: string;
  icon?: React.ReactNode;
  onClick?: () => void;
  href?: string;
  disabled?: boolean;
  destructive?: boolean;
  separator?: boolean;         // renders a divider before this item
}

interface DropdownProps {
  trigger: React.ReactElement;
  items: DropdownItem[];
  placement?: 'bottom-start' | 'bottom-end' | 'top-start' | 'top-end';
}
```

## Notes for AI

- Read: [.agents/engineering.md](../../../.agents/engineering.md)
- Modal and Dialog must use React Portal (`ReactDOM.createPortal`) into `document.body`
- Focus trap: use `focus-trap-react` or implement manually — cycle through focusable elements with Tab/Shift+Tab
- Toast uses Context — `ToastProvider` must wrap the app; `useToast` hook returns `toast()` function
- Overlay backdrop: `--pcampus-color-surface` at 0.6 opacity + `--pcampus-backdrop-blur`
- Animation tokens: `--pcampus-duration-panel` (220ms), `--pcampus-ease-enter`, `--pcampus-ease-exit`
- Positioning (Tooltip/Popover/Dropdown): use `@floating-ui/react` — do not implement positioning from scratch
