## Scenario 1: Theme preset exports prefixed utility mappings

**Expected behavior:** `dist/theme.css` exposes all `--color-pcampus-*` variables needed by pcampus-ui component classes while keeping existing unprefixed mappings.

| Field | Value |
|-------|-------|
| **Input** | Run `npm run build:css` in `code/` |
| **Output** | `dist/theme.css` contains `@theme inline` mappings for all 14 prefixed roles |
| **Preconditions** | G-014 raw theme build is complete |

| Field | Value |
|-------|-------|
| **Input** | Run `npm run test` |
| **Output** | `code/tests/theme.test.ts` validates class usage against theme mappings |
| **Preconditions** | Components use the `*-pcampus-*` class naming convention |

**Expected behavior:** A Tailwind v4 consumer with only `@source` + `@import "@pcampus-studio/ui/dist/theme.css"` can emit non-empty CSS for representative classes.

| **Preconditions** | `@pcampus-studio/ui@1.3.1` build artifacts are available |
